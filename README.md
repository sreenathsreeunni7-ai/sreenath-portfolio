# My Portfolio

A developer portfolio built with React 19 + Vite + Tailwind CSS 4, featuring the "Signal HUD" design style — dark, technical, motion-led.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack

- **React 19** + **Vite 6**
- **Tailwind CSS 4** (via `@tailwindcss/vite`)
- **GSAP** (with ScrollTrigger) — scroll animations
- **Lenis** — smooth scroll
- **Three.js** — 3D centrepiece
- **EmailJS** — contact form

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
